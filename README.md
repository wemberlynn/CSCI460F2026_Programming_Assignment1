Naive Bayes -- Emberlynn McKinney
=================================

The report is available in <CSCI460F2026_Programming_Assignment1.pdf>.

Requirements:
- [Python 3.11+](https://www.python.org/downloads/)
- [Numpy 2.5+](https://numpy.org/install/)
- [Scikit-Learn 1.9+](https://scikit-learn.org/stable/install.html)

To run the project, automatically installing numpy and scikit-learn and
running all tests, execute <CSCI460F2026_Programming_Assignment1.bash>.

To run the project without creating a virtual environment,
execute <CSCI460F2026_Programming_Assignment1.py> directly.
The provided help will describe the available command line arguments.
